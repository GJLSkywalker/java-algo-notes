## 边界表（背下来）

| 类型 | 位数 | 范围 |
|---|---|---|
| `int` | 32 | −2 147 483 648 ~ 2 147 483 647（约 ±2.1×10⁹） |
| `long` | 64 | 约 ±9.2×10¹⁸ |
| `double` | 64 | 约 ±1.8×10³⁰⁸（15–16 位有效数字） |

## 溢出的三种写法（片段）

```java
int a = 1000000000;
long x = 10000000000L;            // ① 字面量超 int 范围，必须加 L

int b = 100000;
long wrong = b * b;               // ② 错：int*int 先溢出，赋给 long 救不回
long right = (long) b * b;        // ② 对：先把一个操作数转 long

long sum = 0;                     // ③ 累加用 long
